# Student Assignment Tracker

## 1. Problem Statement

Students have to do many assignments for different subjects. It can be difficult to remember which assignments are pending and which ones are completed.

This project is made to help students keep their assignments in one place. It allows them to add, view, search, complete, and delete assignments.

## 2. Scope of the Project

This project can be used to keep track of daily college or school assignments.

It can:

* Add new assignments.
* Show all assignments.
* Show pending assignments.
* Mark an assignment as completed.
* Search for an assignment.
* Delete an assignment.

The project is mainly made for simple assignment management. It does not include features like online accounts, notifications, or cloud storage.

## 3. Target Users

This project is mainly for:

* School students.
* College students.
* Anyone who wants to keep track of their assignments.

## 4. High-Level Features

* **Add Assignment:** Add the name, subject, deadline, and priority.
* **View Assignments:** See all the assignments that have been added.
* **Mark as Completed:** Change an assignment from pending to completed.
* **Delete Assignment:** Remove an assignment from the list.
* **Search Assignment:** Find an assignment by its name or subject.
* **View Pending Assignments:** See only the assignments that are still pending.
* **Simple Menu:** Choose what you want to do using numbered options.
